# 技术示例

保存范围明确、具有过程说明的可复现示例。实际曲目的完整资料继续留在本地 `score/`。

## 当前示例

- [四小节六线谱识别](tablature-recognition/bushiyinweijimocaixiangni-opening/README.md)：从裁剪图片到原始识别，再到 MusicXML、MuseScore 工程和 PDF，分析节奏估算和漏闷音。

## 命名与例外范围

目录使用 `<处理任务>/<作品或来源标识>-<片段范围>`，例如 `tablature-recognition/<work>-opening`。每个示例的 README 明确原始来源、引用范围、用途、已知错误、版权状态和复现步骤。

当前只登记上述前四小节。`scripts/public_examples.json` 按精确文件路径与 SHA-256 登记示例文件；推送检查使用每个历史提交自身的清单验证内容。同名文件替换、增加文件或扩大范围都需要重新审查和登记，不允许按整个目录放行。

用户指定片段仅确定项目的公开范围，不表示已取得权利人许可。没有固定小节数的自动免责规则；“适当引用”仍需结合介绍或说明目的、引用必要性、署名及权利人利益判断，见 [著作权法第二十四条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。具体示例如未核实授权，应如实注明，不把引用乐谱视作可自由再利用的素材。
