# 乐理学习

本目录保存乐理概念、曲式分析、练习记录以及与谱面关联的学习笔记。

## 文件组织

短篇主题使用单文件：

```text
theory/
└── <topic-slug>.md
```

需要多个笔记、谱例或媒体文件时，升级为主题目录：

```text
theory/
└── <topic-slug>/
    ├── README.md
    └── assets/
```

- `<topic-slug>` 使用小写 ASCII 单词和连字符，例如 `functional-harmony`、`sonata-form`。
- 主题目录中的 `README.md` 是该主题的索引，负责列出笔记、阅读顺序和关联曲目。
- `assets/` 只保存该主题使用的图片、音频或短谱例，并采用可判断用途的名称。
- 当具体作品的分析需要引用谱面时，使用相对链接指向 `score/<work-slug>/`。

## 笔记要求

每篇正式笔记至少说明：

1. 讨论的概念或作品。
2. 使用的术语、调性、拍号或曲式前提。
3. 谱例、听辨材料或推导过程。
4. 结论与尚存疑问。
5. 参考资料或外部链接。

区分事实、教材观点和个人分析。暂时无法确认的内容明确标记为待核实，不把推测写成结论。

## 命名规则

- 一个文件只承担一个稳定主题，不把不同主题拼入同一篇笔记。
- 修订使用 Git 历史管理，不使用 `new`、`final`、`tmp`、`test2`、`v2` 等名称区分版本。
- 练习、分析和概念笔记仍使用能够表达内容的业务名称；需要分组时再建立有明确职责的子目录并补充 README。
